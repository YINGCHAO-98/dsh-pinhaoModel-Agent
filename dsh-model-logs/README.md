# 模型日志

DSH 的会话内界面插件，仅在拼好模会话中显示，与「对话 / 轨迹 / 上下文」并列。其他 preset 不显示该标签。自动展示当前会话及子模型；无需输入会话 ID，不提供跨会话范围切换。可按模型、状态、输出或错误关键词筛选。

## 数据和判定

- 在宿主 `llm/stream` 实际执行路径记录拼好模（`pin-hao-mo`）及子会话调用。记录模型、provider、会话、起止时间、耗时、停止原因、Token 用量、工具名及最多 16,000 字符的输出摘要。
- 正常 `stop` / `tool-calls` 才标记调用成功；错误、输出超限、取消、中断、缺少结束事件分别记录。不会修改、重试或吞掉模型结果；日志写入失败只告警。
- 每次模型调用的输出默认「未验证」。另以只读方式读取 `capabilities.sqlite` / `delivery.sqlite` 的实际验收记录，标明「验收通过 / 失败 / 阻塞」。通过不代表所有自然语言语义都正确。
- 历史验收可读取；安装前逐次模型输出没有回填。运行中显示耗时；输出摘要与准确耗时在流结束时保存。宿主重启后的未完成调用标为中断。
- 新日志保存在 `~/.dsh-delivery/model-logs.sqlite`，保留最近 10,000 次调用。每个会话查询最多 2,000 次调用及各 200 条任务验收，界面一次最多展示 300 条匹配记录。
- 不保存输入、请求头或凭据。输出摘要做常见密钥格式脱敏，不保证识别全部业务敏感文本。界面仅以文本渲染输出。RPC 是只读服务，不注册模型 Tool。

## 本机挂载

源码位于当前 preset 的 `dsh-model-logs/`。真实 web profile 的 `node_modules/dsh-model-logs` 链接到本目录，`cordis.patch.yml` 挂载 `id: model-logs` / `name: dsh-model-logs`。不要放到 `agent.cordis.yml`：这是宿主和客户端插件，不是模型工具。

首次安装或更改 package/RPC 清单后，从 DSH 的 Harness 菜单重启 Harness。已有会话保留。

卸载时移除 web profile 中 `model-logs` 挂载项及对应符号链接，然后重启；日志数据库保持不变。

## 验证

使用 DSH 附带的 Node 24 运行：

```sh
node --test dsh-model-logs/tests/*.test.mjs
```

覆盖成功、错误、超限、缺少结束事件、取消、中断清理、并发隔离、重启恢复、日志存储失败、非拼好模排除、会话查询隔离、历史验收与实际 DSH Typert 注册器兼容性。
