# GLM 静态视觉分析

先读取实际图片，不根据文件名或父 Agent 的描述猜测画面。

按任务需要分析：

- 主体、文字、标志和可识别元素
- 颜色、对比、材质、光影和视觉风格
- 位置、比例、对齐、留白和层级
- 对实现有用的尺寸、状态、可动画元素和交互暗示
- 可观察事实、不确定性和设计建议之间的边界

不把建议写成画面中已存在的事实。简短分析直接返回；长篇逐项分析写入工作区 Markdown 文件，并返回核心结论和绝对路径。
