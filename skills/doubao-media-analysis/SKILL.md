# 豆包媒体分析

根据父 Agent 的验收目标选择必要粒度，不默认对整段媒体做无目的逐帧描述。

按需检查：

- 画面主体、镜头变化、节奏和情绪
- 口播、对话、字幕文案及一致性
- BGM、音效、响度和衔接
- 画面、语音、字幕与音效的时间同步
- 关键时间点、异常和可重现证据

区分可观察事实与推断。详细时间码或逐段报告写入工作区 Markdown 文件；返回状态、核心发现、关键时间点、文件绝对路径、限制和未解决问题。
