# MiniMax 创意内容

先确认品牌主体、目标受众、发布渠道、时长或字数、语气、必须保留的信息和禁止内容。

- 默认产出一套可直接使用的主方案，不用多个近似版本堆数量。
- 视频脚本写明时间段、画面、文案/口播、音效与转场；只在任务需要时增加分镜。
- 不虚构品牌事实、数据、资质或用户背书。
- 长脚本或多版内容写入工作区 Markdown 文件；返回摘要、绝对路径、自检结果和限制。
